# Pianpian Windows Releases

This repository hosts signed Windows release packages and update metadata for the Pianpian desktop application.

- Download the installer or portable ZIP from GitHub Releases.
- The installer update metadata is verified by the application's embedded Ed25519 public key.
- This repository contains release artifacts only. Do not upload user libraries, PDFs, API keys, or private settings.

Release publishing is automated from the application's source repository after its release workflow and publishing credentials are configured.
